# coreyghilarducci.com

Personal site for Corey Ghilarducci — hire-me homepage, resume, and handcrafted technical writing.

## Local preview

Serve the repo root (GitHub Pages serves files as-is):

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## New writing post

1. Copy `writing/_template.html` to `writing/<slug>/index.html`
2. Fill in title, date, description, and article body
3. Add a list entry on `writing/index.html` and the Writing section on `index.html`

## Archive

Older demos and posts live under `archive/` and are not linked from the current site.
